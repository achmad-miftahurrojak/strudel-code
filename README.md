## Overview

These patterns are written for [Strudel](https://strudel.tidalcycles.org/), a browser-based live coding environment for algorithmic composition. The collection focuses on layered rhythm, synthesis, effects, and quick experimentation.

## Patterns

### REDRED_CORTIS.js

A multi-layer arrangement with:

- Synth lead and melodic movement.
- Sub-bass and harmonic intervals.
- Kick and snare patterns.
- Distortion, filtering, delay, and stereo placement.
- Interactive gain controls.

## Quick start

1. Open the [Strudel web editor](https://strudel.tidalcycles.org/).
2. Open `REDRED_CORTIS.js` from this repository.
3. Paste the pattern into the editor.
4. Press `Ctrl+Enter` or `Cmd+Enter` to play.
5. Change the pattern while it runs.

    $synth: n('0 2 4 7').scale('C:major').s('triangle').gain(0.5)
