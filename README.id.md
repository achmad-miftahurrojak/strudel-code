## Ringkasan

Pattern ini ditulis untuk [Strudel](https://strudel.tidalcycles.org/), lingkungan live coding berbasis browser untuk komposisi algoritmik. Koleksi ini berfokus pada ritme berlapis, sintesis, efek, dan eksperimen cepat.

## Pattern

### REDRED_CORTIS.js

Komposisi berlapis dengan synth lead, bass, drum, efek distorsi/filter/delay, stereo placement, dan kontrol gain interaktif.

## Mulai cepat

1. Buka [Strudel web editor](https://strudel.tidalcycles.org/).
2. Buka atau salin <code>REDRED_CORTIS.js</code>.
3. Tekan <code>Ctrl+Enter</code> atau <code>Cmd+Enter</code>.
4. Ubah kode saat pattern berjalan.

    $synth: n('0 2 4 7').scale('C:major').s('triangle').gain(0.5)
