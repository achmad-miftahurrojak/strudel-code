## 개요

[Strudel](https://strudel.tidalcycles.org/)용 패턴입니다. 브라우저 기반 live coding 환경에서 레이어드 리듬, 신시사이저, 이펙트, 빠른 실험을 다룹니다.

## 패턴

### REDRED_CORTIS.js

신스 리드, 베이스, 드럼, distortion/filter/delay, stereo 배치, gain 제어를 포함한 레이어드 구성입니다.

## 빠른 시작

1. [Strudel web editor](https://strudel.tidalcycles.org/)를 엽니다.
2. <code>REDRED_CORTIS.js</code>를 열거나 내용을 복사합니다.
3. <code>Ctrl+Enter</code> 또는 <code>Cmd+Enter</code>를 누릅니다.
4. 재생 중 코드를 수정합니다.

    $synth: n('0 2 4 7').scale('C:major').s('triangle').gain(0.5)
